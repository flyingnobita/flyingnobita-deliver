# Delivery

The delivery suite coordinates a change from an agreed brief through implementation, review, verification, and shipping.

## Language

**Delivery suite**:
The four companion skills: Deliver, Setup, Review, and Retro.
_Avoid_: Deliver skill when referring to all four

**Deliver**:
The skill that coordinates an end-to-end delivery run.

**Setup**:
The companion skill for delivery prerequisites, configuration, and host validation.

**Review**:
The companion skill for reviewing and repairing an existing branch.

**Retro**:
The companion skill for examining a delivery run and identifying improvements.
