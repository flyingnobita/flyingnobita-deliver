# Delivery

The delivery suite coordinates a change from an agreed brief through implementation, review, verification, and shipping.

## Language

**Delivery suite**:
The five companion skills: Deliver, Implement, Setup, Review, and Retro.
_Avoid_: Deliver skill when referring to all five

**Deliver**:
The skill that coordinates an end-to-end delivery run.

**Implement**:
The companion skill that builds agreed tickets in parallel implementer workers and lands them on the user's branch as linear history, without Deliver's grilling, planning and review stops.
_Avoid_: implement (alone), which names the unrelated `mattpocock-implement` skill

**Setup**:
The companion skill for delivery prerequisites, configuration, and host validation.

**Review**:
The companion skill for reviewing and repairing an existing branch.

**Retro**:
The companion skill for examining a delivery run and identifying improvements.
